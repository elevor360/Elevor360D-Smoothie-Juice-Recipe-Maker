Elevor360D Smoothie & Juice Recipe Maker V1

50 individually drafted recipes across 6 categories. Includes search, favourites, serving-size calculator, personal recipes, shopping lists, planner, large graphic timers, backup/restore, offline PWA installation and rotating advertising.

Upload index.html, app.js, recipes.json, icon.svg, manifest.webmanifest, sw.js and advertising/ to GitHub Pages repository root. Keep Elevor360D_Smoothie_Juice_Recipe_Manager_V1.html on your computer, not in the public website.

To edit built-in recipes: open manager locally, import recipes.json, edit, export recipes.json, upload to GitHub. Service worker fetches recipes.json network-first and uses offline cached copy when offline.

Advertising folder and Sunset Banner.png preserved from previous working apps.

Recipes are editorial drafts, not independently tested. Check measurements, allergens and food hygiene before publication.
